18-4 ECharts

ECharts 凹凸排名图与 3D 金属柱状图 · 沈畅

复刻 ECharts 官方示例 bump-chart 与 metal-bar3d： 左侧是 9 个对象 6 年排名变化的凹凸图（Bump Chart），右侧是 20×20 网格的 bar3D 金属质感柱状图。两个库文件均已下载到本地 cdn/echarts/ 目录，页面不依赖任何远程 CDN。

凹凸排名图（Bump Chart）

纵轴为排名（#1 在最上方，越靠上名次越高），横轴为年份

3D 金属柱状图（Metal Bar3D）

20×20 网格随机高度，lambert 光照 + 金属色材质；拖拽可旋转、滚轮可缩放

实现说明

  • 官方示例的 CDN 脚本已下载到本地：cdn/echarts/echarts.min.js（约 1.0 MB）与 cdn/echarts/echarts-gl.min.js（约 640 KB）。
  • 凹凸图的纵轴使用 inverse: true 让第 1 名显示在最上方，并用 axisLabel.formatter: '#{value}' 输出 #1~#9。
  • 每条折线通过 endLabel 在右端直接显示系列名，和官方示例一致，不再单独放图例。
  • 3D 柱状图依赖 echarts-gl，必须在 echarts 之后引入；否则 bar3D 无法渲染。
  • 3D 图使用 shading: 'lambert' 配合金属色材质与主光源，在纯黑环境下呈现金属光泽，需要浏览器支持 WebGL。

核心代码

// 1. 本地引入（先 echarts，再 echarts-gl）
<script src="cdn/echarts/echarts.min.js"></script>
<script src="cdn/echarts/echarts-gl.min.js"></script>

// 2. 凹凸图：排名纵轴反向
var chart = echarts.init(el);
chart.setOption({
  xAxis: { type: 'category', data: years },
  yAxis: {
    type: 'value', inverse: true, min: 1, max: 9,
    axisLabel: { formatter: '#{value}' }
  },
  series: names.map((name, i) => ({
    name: name, type: 'line', smooth: true,
    symbolSize: 13, lineStyle: { width: 3 },
    endLabel: { show: true, formatter: '{a}' },
    data: ranks[i]
  }))
});

// 3. 3D 金属柱状图
chart.setOption({
  grid3D: {
    boxWidth: 190, boxDepth: 190, boxHeight: 90,
    environment: '#000',
    light: { main: { intensity: 1.6, shadow: true } }
  },
  series: [{
    type: 'bar3D', shading: 'lambert',
    itemStyle: { color: '#cdbfa6' }, data: data
  }]
});
