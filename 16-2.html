JavaScript 对象与字符串

姓名：沈畅 · 对象：键值对 / 访问 / 增删改 / 遍历 · 字符串：字符序列 / 不可变 / 常用方法

对象像一个"收纳盒"，用「键: 值」的形式描述一个事物的多项信息；字符串则是一串按顺序排列的字符，每个字符都有自己的下标。
下面两部分都可以直接点击操作：对象区可以读取、增删改、遍历；字符串区可以点击字符格子查看下标访问，并逐个运行常用方法。

一、对象 Object 花括号 { } 里是一组「键: 值」

对象长什么样

键（紫色）本质上是字符串，值（绿色）可以是数字、字符串、数组甚至另一个对象。

动手操作这个对象

① 读取属性（点击键名）
② 增加 / 修改 / 删除属性
③ 遍历所有属性
操作结果会显示在这里。

对象里还能再套对象（嵌套）

const sc_course = {
姓名: "沈畅",
课程: {
名称: "高级网页设计",
章节: 16,
技术: [HTML, CSS, JS]
}
}

读取嵌套里的值要一层一层往下走：sc_course.课程.名称 → "高级网页设计"

二、字符串 String 一串字符，每个字符都有下标，从 0 开始

字符串就是排好队的字符

点击任意一个字符，查看用下标取出它的结果。

字符串是不可变的

字符串一旦创建就不能被修改，任何"修改"其实都会产生一个新字符串。
