电商全站系统架构图 · 沈畅

整张架构图由 <canvas> 手工绘制：圆角矩形、分层色带、连线箭头、流动光点与文字排版全部用 Canvas 2D API 完成， 不依赖任何第三方绘图库。把鼠标移到任意模块上，可以看到它的职责说明与调用关系高亮。

用户层 接入层 业务服务层 支撑服务层 数据层 运维与安全
— 提示 将鼠标移到任意模块上，查看该模块的职责与关键说明。

架构说明

  • 用户请求先到 CDN（静态资源）与 Nginx（负载均衡），再统一由 API 网关 鉴权、路由。
  • 业务服务保持无状态，可水平扩容；热点数据走 Redis，下单、库存变更通过 Kafka 异步削峰。
  • 商品检索交给 Elasticsearch，数据落在 MySQL 主从集群，图片视频存 OSS，离线报表进数据仓库。
  • 运维与安全层横向支撑全站：监控告警、日志追踪、风控防刷。
  • 图中连线表示调用或数据流向，流动光点表示请求在链路上的移动方向。

核心代码

// 绘制圆角矩形模块
function drawBox(box, active) {
    ctx.beginPath();
    roundRect(ctx, box.x, box.y, box.w, box.h, 8);
    ctx.fillStyle = active ? box.fillHover : box.fill;
    ctx.fill();
    ctx.strokeStyle = active ? box.color : box.stroke;
    ctx.stroke();
    ctx.fillStyle = '#e2e8f0';
    ctx.font = 'bold 14px "Microsoft YaHei"';
    ctx.fillText(box.name, box.x + box.w / 2, box.y + 20);
}

// 连接线 + 箭头
function drawEdge(from, to, t) {
    const p1 = edgePoint(from, to);
    const p2 = edgePoint(to, from);
    ctx.beginPath();
    ctx.moveTo(p1.x, p1.y);
    ctx.lineTo(p2.x, p2.y);
    ctx.stroke();
    arrowHead(p1, p2);
}

// 逐帧绘制，让光点在连线上流动
function loop(now) {
    draw(now);
    requestAnimationFrame(loop);
}
