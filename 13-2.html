SVG 图标原理：Lucide 每个图标都是独立的矢量路径。使用 <i data-lucide="home"></i> 占位， 引入 lucide.min.js 后调用 lucide.createIcons()，脚本会扫描页面中的 data-lucide 属性， 把占位元素替换为真正的 <svg> 内联节点，因此它本质上是「矢量图形」，可用 CSS 精确控制描边粗细与颜色。

用法示例 CODE 
<script src="cdn/lucide/lucide.min.js"></script>

<i data-lucide="home"></i>            <!-- 基础图标 -->
<i data-lucide="heart" width="48" height="48"></i> <!-- 指定尺寸 -->

<script>
  lucide.createIcons();   // 扫描 data-lucide 并替换为 <svg>
</script>
