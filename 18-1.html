18-1 Canvas 动画

Canvas 粒子文字动画 · 沈畅

先用离屏 canvas 把「沈畅」两个字画出来，逐像素采样得到文字轮廓的点阵， 再让几千个小粒子用弹性缓动飞向各自的目标点，聚合成文字。 整个动画由 requestAnimationFrame 驱动，鼠标移入画布会把粒子吹散，松开后它们会重新聚拢。

鼠标移入画布：粒子会被推开，移开后重新聚合
粒子 0 0 FPS

实现步骤

  • 创建离屏 canvas，用 fillText('沈畅') 在中心绘制大字。
  • 用 getImageData 扫描像素，透明度大于 128 的坐标记为文字轮廓点。
  • 点数过多时按步长抽稀，控制在 3000~4000 个粒子，保证 60 FPS。
  • 每个粒子从画布边缘随机出发，用弹簧模型 v += (target - pos) * k 收拢。
  • requestAnimationFrame 每帧先清屏，再画背景星点与粒子，最后统计帧率。
  • 鼠标坐标与粒子距离小于 90px 时施加反向推力，形成被吹散的效果。

核心代码

// 1. 采样文字像素，得到目标点
const off = document.createElement('canvas');
off.width = W; off.height = H;
const octx = off.getContext('2d');
octx.font = 'bold ' + size + 'px "Microsoft YaHei"';
octx.textAlign = 'center';
octx.fillText('沈畅', W / 2, H / 2);
const data = octx.getImageData(0, 0, W, H).data;
// 每隔 5px 取一个不透明像素作为粒子目标

// 2. 每帧弹性逼近目标
function update() {
    particles.forEach(p => {
        p.vx += (p.tx - p.x) * 0.05;
        p.vy += (p.ty - p.y) * 0.05;
        p.vx *= 0.86; p.vy *= 0.86;
        p.x += p.vx; p.y += p.vy;
    });
}

// 3. 循环绘制
function loop() {
    update();
    draw();
    requestAnimationFrame(loop);
}
loop();
