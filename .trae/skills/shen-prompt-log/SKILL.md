# 提示词记录（shen_prompt.md）

在执行任何实际任务之前，先把本次用户提示词以追加方式写入项目根目录的 `shen_prompt.md`，绝不覆盖已有内容。

## 步骤

1. 用 `Get-Date -Format "yyyy-MM-dd-HH-mm"`（Windows PowerShell）获取当前时间，24 小时制。
2. 确认本次会话实际使用的模型 ID。
3. 读取 `shen_prompt.md` 末尾，确认最后一条记录的结尾位置。
4. 在文件末尾追加一条记录，格式如下（整体以 `---` 分隔线包裹）：

   ```
   ---
   ## yyyy-mm-dd-hh-mm
   **模型：** <实际使用的模型 ID>
   **提示词：** <用户原始提示词，完整保留，不做删减或改写>
   ---
   ```

5. 若文件末尾已经是 `---`，先补一个空行再追加，避免分隔线粘连成一条。

## 约束

- 只追加，不修改、不删除、不重排已有记录。
- 提示词原文逐字保留，包括反引号、标点和中英文混排。
- 即使用户没有明确要求记录，只要本项目的 AGENTS.md 规则要求记录，就先完成本步骤再执行任务本身。
