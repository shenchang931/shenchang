实现说明

  • Mermaid 脚本已下载到本地：cdn/mermaid/mermaid.min.js（约 2.57 MB），页面直接以 <script src> 引入。
  • 使用 mermaid.initialize({ startOnLoad: false }) 关闭自动渲染，再调用 mermaid.run() 手动渲染两个图，方便统一主题。
  • 流程图用 subgraph 划分五个层级，B3 用菱形表示判断节点，虚线 -. 表示反馈闭环。
  • ER 图使用 Mermaid 的鸦爪（crow's foot）语法：||--o{ 表示一对多，||--o| 表示一对零或一。
  • 主题通过 theme: 'base' 与 themeVariables 定制，与页面配色保持一致。

核心代码

// 1. 本地引入
<script src="cdn/mermaid/mermaid.min.js"></script>

// 2. 关闭自动渲染并定制主题
mermaid.initialize({
  startOnLoad: false,
  theme: 'base',
  themeVariables: {
    primaryColor: '#dbeafe',
    primaryBorderColor: '#93c5fd',
    lineColor: '#94a3b8',
    edgeLabelBackground: '#ffffff'
  },
  flowchart: { curve: 'basis', nodeSpacing: 42 }
});

// 3. 手动渲染页面里的 .sc_mermaid
mermaid.run({ nodes: document.querySelectorAll('.sc_mermaid') });
