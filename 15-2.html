一、条件结构（分支）

1. if...else if...else 多分支 根据条件从上到下依次判断，命中即执行

语法：条件为 true 执行对应代码块，所有条件都不满足时执行 else 分支。

if (sc_score >= 90) { // 优秀 } else if (sc_score >= 60) { // 及格 } else { // 不及格 }

2. switch 多值匹配 精确匹配某一个值时更清晰

switch (sc_day) { case "六": case "日": sc_r = "休息日"; break; default: sc_r = "工作日"; }

二、循环结构

1. for 循环 已知循环次数时首选

for (var sc_i = 1; sc_i <= 9; sc_i++) { // 初始化; 条件; 步进 }

2. while 与 do...while 先判断后执行 / 先执行后判断

while (sc_i <= 100) { sc_sum += sc_i; sc_i++; } do { sc_sum += sc_i; sc_i++; } while (sc_i <= 100); // 至少执行一次

3. break 与 continue break 跳出整个循环，continue 跳过本次
