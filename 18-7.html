18-7 three.js

three.js 四种 3D 图表 · 沈畅

不借助图表库，直接用 three.js 搭建四个三维数据图表：柱状图、散点图、环形饼图与曲面图。 每个图表都有独立的场景、相机、光照与 OrbitControls，可拖动旋转、滚轮缩放。 脚本已下载到本地 cdn/three/，页面不依赖远程 CDN。

实现说明

  • three.js 脚本已下载到本地：cdn/three/three.min.js 与 cdn/three/OrbitControls.js（r128，非模块版本，可直接用 <script src> 引入）。
  • 每个图表用独立的 WebGLRenderer、Scene、PerspectiveCamera，四个画布互不影响。
  • 柱状图用 BoxGeometry 按数据缩放 scale.y，柱体高度决定颜色深浅。
  • 散点图用 BufferGeometry 写入位置与颜色属性，PointsMaterial 开启 vertexColors。
  • 环形饼图用 Shape 绘制扇环路径，再由 ExtrudeGeometry 拉伸并加倒角。
  • 曲面图逐顶点改写 position.y 后调用 computeVertexNormals()，光照才正确。
  • 四张图共享一个 requestAnimationFrame 循环，窗口尺寸变化时统一重新计算画布与相机比例。

核心代码

// 1. 本地引入
<script src="cdn/three/three.min.js"></script>
<script src="cdn/three/OrbitControls.js"></script>

// 2. 场景 / 相机 / 控制器
var renderer = new THREE.WebGLRenderer({
  canvas: canvas, antialias: true, alpha: true
});
var scene = new THREE.Scene();
var camera = new THREE.PerspectiveCamera(45, 1, 0.1, 200);
camera.position.set(9, 8, 11);
var controls = new THREE.OrbitControls(camera, canvas);
controls.autoRotate = true;

// 3. 柱状图：按数据拉伸盒体
var bar = new THREE.Mesh(
  new THREE.BoxGeometry(0.8, 1, 0.8),
  new THREE.MeshStandardMaterial({
    color: '#38bdf8', roughness: 0.4, metalness: 0.25
  })
);
bar.scale.y = value;        // 数据映射高度
bar.position.y = value / 2; // 底部贴地

// 4. 环形饼图：扇环路径 + 挤出
var shape = new THREE.Shape();
shape.absarc(0, 0, 3, start, end, false);
shape.absarc(0, 0, 1.6, end, start, true);
var geo = new THREE.ExtrudeGeometry(shape, {
  depth: 0.6, bevelEnabled: true, bevelSize: 0.05
});
mesh.rotation.x = -Math.PI / 2;

// 5. 统一渲染循环
function animate() {
  requestAnimationFrame(animate);
  charts.forEach(c => {
    c.controls.update();
    c.renderer.render(c.scene, c.camera);
  });
}
