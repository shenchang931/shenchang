17-6 Promise / async

用 Promise 与 async / await 包一顿饺子

把包饺子的工序写成异步流程：Promise.race 处理「线上、线下同时买原料，谁先到算谁」， Promise.all 处理「和面、和馅必须都完成才能包饺子」，其余步骤用 await 顺序执行。 每一步都用 setTimeout 模拟耗时，页面会实时显示进行状态与日志。

核心代码

// 用 setTimeout 模拟每一步的耗时，返回 Promise
function sc_wait(label, ms) {
    return new Promise(function (resolve) {
        setTimeout(function () { resolve(label); }, ms);
    });
}

async function sc_makeDumplings() {
    // ① 线上、线下同时买原料，谁先完成用谁
    const buyer = await Promise.race([
        sc_wait('线上购买', 6000),
        sc_wait('线下采购', 8000)
    ]);
    console.log(buyer + '先买到原料');

    // ② 取原料
    await sc_wait('取原料', 2000);

    // ③ 和面、和馅必须都完成才能继续
    await Promise.all([
        sc_wait('和面', 5000),
        sc_wait('和馅', 4000)
    ]);

    // ④⑤⑥ 顺序执行：包饺子 → 煮饺子 → 吃饺子
    await sc_wait('包饺子', 6000);
    await sc_wait('煮饺子', 8000);
    await sc_wait('吃饺子', 3000);
}

sc_makeDumplings();

知识点

  • Promise.race([a, b])：只要其中一个完成就返回，另一个 Promise 仍在后台执行，但结果被忽略 —— 这就是「线上线下同时买，谁先到算谁」。
  • Promise.all([a, b])：全部成功才 resolve，耗时等于最慢的那个；如果任意一个 reject，整体立即失败。
  • await 只能写在 async 函数内，它暂停的是当前函数，页面其它交互照常运行。
  • 每一步的实际时长 = 设定毫秒数 ÷ 演示速度，页面进度条与日志只是 Promise 状态的可视化。
