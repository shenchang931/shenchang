17-1 数据格式

JSON 数据格式演示

JSON（JavaScript Object Notation，JavaScript 对象表示法）是一种轻量级的文本数据交换格式。 它由键值对和有序列表组成，既可被 JavaScript 的 JSON.parse() 解析为对象， 也能用 JSON.stringify() 把对象序列化成文本，是前后端数据交互中最常用的格式。

一、JSON 语法规则

规则 01

键必须用双引号

属性名只能是双引号包裹的字符串，单引号、无引号都不合法。

规则 02

值只能是六种类型

字符串、数字、布尔值、null、对象、数组，不允许函数、undefined、日期对象。

规则 03

键值对之间用逗号分隔

同一层级的成员以逗号隔开，最后一个成员后面不能多写逗号。

规则 04

不能写注释

标准 JSON 不支持注释，需要说明时可另加一个专门的字段。

二、JSON 中的六种数据类型

字符串

string
"沈畅"

必须用双引号包裹，内部的双引号需转义为 \"。

数字

number
2026 / -3.14 / 1.5e10

支持整数、小数和科学计数法，不支持 NaN 与 Infinity。

布尔值

boolean
true / false

全部小写，写成 True 或 TRUE 都会解析失败。

空值

null
null

表示空值，必须小写，不能用 undefined 代替。

对象

object
{ "城市": "北京" }

无序的键值对集合，用花括号包裹，可多层嵌套。

数组

array
[ "HTML", "CSS", "JS" ]

有序的值列表，用方括号包裹，元素类型可混合。
